# Online Office Tools Skill

Use this skill to navigate, select, and interact with client-side utilities on https://onlineofficetools.com.

## Available Capabilities
- **PDF Manipulation**: Merge, split, rotate, compress, convert PDF to images, extract text.
- **Documents & Word**: Convert DOCX to HTML, HTML to DOCX, compare DOCX files.
- **Spreadsheets**: View XLSX, convert XLSX to CSV, CSV to XLSX, edit CSV tables.
- **Media & Audio/Video**: Resize, crop, convert images, audio visualizer, video trimmer, watermark.
- **Developer Utilities**: JSON Formatter, Base64 encoder/decoder, UUID generator, password generator.

All operations execute 100% locally in the user's browser without uploading private documents to external servers.
